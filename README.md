# DJS Antariksh — Robotics & Python Coursework

Work from my time as a Coding & Robotics Team Member at DJS Antariksh (DJ Sanghvi's student robotics team), covering ROS 2 package development and Python data-handling exercises.

## 🤖 ROS 2 Packages

Four ROS 2 (`ament_python`) packages built and tested in a Linux/TurtleBot simulation environment:

| Package | What it does |
|---|---|
| `task1_package` | Custom ROS 2 nodes (`node_1`, `node_2`, `node_3`) for inter-node communication fundamentals |
| `task2_package` / `task2_interface` | Client-server architecture with a custom `.srv` service interface |
| `task3_package` / `task3_interface` | TurtleBot control node computing angular velocity via a service server, plus a node driving the bot in an infinity-shaped trajectory |
| `task4_package` | Launch-file-based node that programmatically moves the turtle to target waypoints |

These cover core ROS 2 concepts: topics, services, custom interfaces, launch files, and closed-loop motion control — building toward the path-planning and obstacle-avoidance work used in autonomous rover navigation.

## 🐍 Python & Data Exercises

- `python1.ipynb` – `python6.ipynb` — general Python/data-handling exercises, including work with `Real_Estate.csv` and `diabetes2.csv`
